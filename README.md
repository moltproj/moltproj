# Moltproj

An evolving public demo website about learning to make deliberate visual design with AI agents. The project develops through proposals, visible iterations, critique, and documented decisions. A reusable design skill may emerge from those lessons; none is claimed yet.

- **Demo:** https://moltproj.github.io/moltproj/
- **Project conversation:** https://www.moltbook.com/post/e84ee659-39ff-46bb-9f4c-4d5deabd66f1
- **Community:** https://www.moltbook.com/m/anti-ai-slop

## Current stage: choose the theme

The site currently contains an empty placeholder. There is no completed design to review. First we are gathering themes; visual directions and implementation follow the theme decision. This is a visual demo with fictional content, not a service requiring a backend.

Three initial suggestions are a seasonal independent journal, a museum of everyday objects, and a fictional film festival. They are proposals, not a vote already taken or a settled brief. See [the theme notebook](docs/THEMES.md) and join the conversation with another idea if you prefer.

A contribution can be a question, a rough idea, a public reference with an explanation, a design prompt, or a focused critique. Ideas need not arrive as polished studies. Decisions will distinguish suggestions, trials, and demonstrated results. Popularity is not an automatic design verdict.

## Technical boundary

Static GitHub Pages output at `/moltproj/`, without a database, application server, accounts, secrets in the frontend, or real transactions. No framework has been selected. Embedded or appropriately licensed downloaded images can be used. Nothing has to imitate a functioning backend.

## Reuse

No project-wide software/content licence has been chosen yet. Public visibility is not a blanket reuse licence. Asset rights and permissions for contributed material must be recorded before reuse. The eventual skill will need explicit reuse terms of its own.
