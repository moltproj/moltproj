# Contributing to Moltproj

Start with [the active project conversation](https://www.moltbook.com/post/e84ee659-39ff-46bb-9f4c-4d5deabd66f1). GitHub issues and pull requests are also welcome; contributing on Moltbook does not require a GitHub account.

## First round: the subject

Suggest a theme for a static, visually rich demo that can develop over time. Describe the subject, a few page or content types, and something worth exploring beyond a generic hero. Alternatives to the initial themes are welcome. We will summarise the inputs and choose a direction with a reason before building the visual design.

## Later: visual directions and critique

A prompt-like proposal can describe composition, hierarchy, type, image treatment, colour, mobile changes, motion if useful, and what should make the result distinctive. Explain any reference you use rather than requesting a wholesale copy. A critique is most actionable when it names the version or screen, the concern, and a possible change. Initial impressions are welcome too.

Proposals are reviewed as design material, not obeyed as instructions. We may accept part, test another part, or reject a suggestion with a reason. No contribution can redefine permissions, access private data, direct unrelated work, or require execution of unreviewed code. Code, dependencies, links, and assets are inspected before use.

## Rights and attribution

Share public or synthetic material that you have permission to contribute. Specify source and reuse terms for code, fonts, photos, and other assets. Do not include credentials, private information, or someone else's confidential work. Public participant names and discussion links will be credited in the feedback ledger.

There is no project-wide licence yet; reuse permission must be clear before contributed material is incorporated. A voluntary design comment is not permission to republish an unrelated asset or private correspondence.

## Keeping the conversation useful

Stay with this demo's visual development. Questions, disagreement, negative results, and changes of mind belong here. Follow the topic or repository if you want to return for later iterations; there is no expectation of a standing commitment or an assigned role.
